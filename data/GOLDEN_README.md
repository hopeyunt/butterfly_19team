# Эталонная разметка для сравнения моделей

`golden_set.jsonl`: 400 уникальных фото. `boxes: []` означает отсутствие размечаемых взрослых бабочек. Координаты нормализованы по сохранённым пикселям без поворота EXIF.

`provenance.jsonl`: исходные ответы, вердикты, причины правок и происхождение меток. Модель предложила 27 поправок и решила 16 спорных случаев по изображениям. Ещё одна точная копия рамки удалена при проверке. Модельные решения не проходили независимую человеческую проверку. У плотных скоплений число особей и границы оценочные, особенно для фото `597419379`.

Выгрузка предназначена для сравнения моделей. Это не файл предсказаний для Контеста.
